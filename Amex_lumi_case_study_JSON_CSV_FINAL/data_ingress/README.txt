Input files and control file

- demo_data.jsonl is the supplied demo input. It contains 20 employee records in a JSON array.
- control.properties contains record_count=18 because two intentionally invalid JSON records are rejected.
- control_csv.properties is set to record_count=0 for a duplicate-only CSV rerun; use record_count=84 for the first load into an empty warehouse.
- error_logs/error_records.txt contains structured JSON error records from the splitter and Beam.
- split_chunks/ is generated by the Phase 2 PySpark job; it is intentionally not checked in.

To demonstrate the Phase 3 mismatch path, temporarily change control.properties to record_count=4. The Airflow validation task should then fail with expected=4 and actual=3.
